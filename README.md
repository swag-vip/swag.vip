# USERNAME TRACKER

>  made by **5w2g**

## Description

Un outil qui scanne **27+ plateformes** en parallele pour detecter les comptes associes a un nom d'utilisateur. Interface GUI avec barre de progression et resultats en temps reel.

## Plateformes supportees

GitHub, GitLab, Bitbucket, Reddit, Chess.com, HackerRank, Roblox, Gravatar, Keybase, Twitter/X, TikTok, Instagram, Pinterest, SoundCloud, DeviantArt, Tumblr, VK, Flickr, Replit, Kaggle, Steam, Medium, YouTube, Twitch, Spotify, LinkedIn, Snapchat

## Installation

```bash
pip install requests Pillow
```

## Utilisation

```bash
python username-tracker.py
```
