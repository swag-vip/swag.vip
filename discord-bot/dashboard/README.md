# Discord Bot Dashboard

Dashboard web pour contrôler ton bot Discord depuis GitHub Pages.

## Setup

1. Ouvrir `index.html` dans un navigateur
2. Entrer l'URL de ton backend + la clé API
3. Ajouter tes bots et les démarrer

## Backend

Le backend API tourne séparément (Flask + discord.py).
Voir `backend.py` dans le dossier parent.
